# tcr-documents-explorer
<!-- dash-content-start -->

Documents are stored on a Cloudflare R2 bucket. This makes it easier for everyone to download what they need !

## Features
  - In-browser file preview
    - PDF documents
    - Images
    - Text files
    - Markdown
    - CSV
    - Logpush files
  - In-browser file editing
  - Folder upload support
